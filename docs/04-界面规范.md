# 04 · 界面规范

> 目标：手机 3 秒扫读，知道「今天哪个品种有把握、往哪走、为什么」。信息分层：卡片只给结论，详情给证据。

---

## 1. 设计原则

| # | 原则 | 落地 |
|---|---|---|
| U1 | **3 秒法则** | 卡片首屏可读信息 ≤ 4 项：品种、方向、幅度、更新时间 |
| U2 | **结论前置** | 卡片永不出现资讯条目；资讯只在详情与简报 |
| U3 | **颜色不单独承载信息** | 方向同时用箭头/文字表达（红涨 ▲、绿跌 ▼、灰震荡 —） |
| U4 | **板块可扫** | 按板块分组展示（能化/油脂油料/软商品/黑色/农副），组标题带计数 |
| U5 | **时间诚实** | 每卡显式展示「研判时间」与「行情时间」，两者分开 |
| U6 | **留白优先** | 卡片内边距 ≥ 14px，行距 1.5，数值字号最大 |
| U7 | **可点开才复杂** | 任何超过 2 行的解释都进详情抽屉 |

## 2. 信息架构

```
首页 Dashboard
├─ Header：品牌 | 实时状态灯 | 研判模式 | 手工录入
├─ OilTicker：WTI / Brent / SC / 阿曼（含迷你走势）
├─ SummaryStrip：今日有把握品种数 | 看涨数 | 看跌数 | 震荡数 | 数据更新时间
├─ 板块分组
│   ├─ 能源化工 (10)
│   │   └─ 品种卡片 ×10
│   ├─ 油脂油料 (4)
│   ├─ 软商品 (3)
│   ├─ 黑色 (2)
│   └─ 农副 (2)
├─ 盘面异动（可选折叠）：|涨跌|≥3% 的品种
└─ Footer：数据源状态摘要 | 免责声明

详情抽屉（点卡片）
├─ 头部：品种名 + 代码 + 板块 + 方向徽标 + 幅度
├─ 双时间行：研判时间 / 行情时间 / 模型版本
├─ 趋势图：近 30 日收盘 + 当日预测区间
├─ 贡献者拆解：横向条形（名称 / 数值 / 权重 / q / 贡献）
├─ 今日因子权重：供给 / 需求 / 库存 / 成本 / 情绪
├─ Top 利多 / 利空（3 条，来自 news_extract，可跳原文）
├─ 置信度说明：原始 → 校准后；是否事件日折减
└─ 修订历史：时间 / 原方向 → 新方向 / 触发资讯

简报页 Digest        ：按板块分组的当日汇总 + 一键导出
评分页 Scorecard     ：昨日命中/失误 + 失误归因 + 滚动命中率曲线
数据源页 Sources     ：每源状态 / 最近成功 / 失败原因 / 手动触发
```

## 3. 卡片规格（最重要的组件）

### 3.1 结构

```
┌───────────────────────────────────────────────┐
│ 白糖 SR                        [DS] [事件日]  │   ← 品种名 20px/700；右侧模型来源徽标
│                                               │
│   ▼ 看跌   偏空  31                           │   ← 方向 26px；bucket 15px；signal 32px/800
│                                               │
│   传导  ICE 美棉 +0.62% → 偏多  +8.9           │   ← 仅当 q>0 时展示；单行省略号
│                                               │
│   研判 08:31 · 行情 09:42 · 置信 52%           │   ← 11px muted，两项时间分开
└───────────────────────────────────────────────┘
```

### 3.2 字段与规则

| 区域 | 内容 | 规则 |
|---|---|---|
| 品种名 | 中文名 | 20px / 700；命中热搜词时红色高亮 |
| 代码 | `SR` | 12px / 500 / muted，紧贴名字右侧 |
| 方向 | 看涨 ▲ / 看跌 ▼ / 震荡 — | 26px；红(#d92b2b) / 绿(#0e9f6e) / 灰(#64748b) |
| 幅度 | 强多/偏多/震荡/偏空/强空 | 15px；与方向同色，浅底胶囊 |
| signal | 整数 -100~100 | 32px / 800；正负号显式 |
| 传导行 | `传导 {外盘} {±x.xx%} → {方向} {signal}` | 仅 `q>0`；单行 `text-overflow: ellipsis` |
| 研判时间 | `prediction.asof` | 格式 `08:31`；跨日显示 `11-08 15:10` |
| 行情时间 | 最新 `quote_1m.ts` | 同上；超 10 分钟未更新变橙 |
| 置信度 | `confidence × 100` | 整数百分比 |
| 徽标 | `DS` / `规则` / `事件日` / `外盘缺失` | 最多 2 个，超出折叠为 `+n` |

### 3.3 状态

| 状态 | 视觉 |
|---|---|
| 正常 | 白底、细边框、轻阴影 |
| 盘中修订 | 右上角红点脉冲 + 卡片左侧 3px 品牌色竖条 |
| 数据缺失 | 整卡降透明度 0.6 + 「数据缺失」徽标 |
| 事件日 | 琥珀色小徽标「事件日」，置信度已折减 |
| 加载中 | 骨架屏（保持同等高度，避免跳动） |
| 不可交易（动力煤/小麦） | 不在首页展示，仅在「已下市」折叠区 |

### 3.4 网格

- ≥1280px：4 列
- 768~1279px：3 列
- 480~767px：2 列
- <480px：1 列（卡片高度压缩到 128px，传导行单行省略）

## 4. 视觉系统

| Token | 值 | 用途 |
|---|---|---|
| `--bull` | `#d92b2b` | 看涨（中式红） |
| `--bull-soft` | `#fdecec` | 看涨浅底 |
| `--bear` | `#0e9f6e` | 看跌（中式绿） |
| `--bear-soft` | `#e7f8f1` | 看跌浅底 |
| `--neutral` | `#64748b` | 震荡、次要文字 |
| `--brand` | `#1d4ed8` | 品牌、链接、修订竖条 |
| `--bg` | `#f5f7fb` | 页面底 |
| `--surface` | `#ffffff` | 卡片底 |
| `--line` | `#e5e9f2` | 分割线 |
| `--radius` | `12px` | 卡片圆角 |

字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
数字：`font-variant-numeric: tabular-nums`（等宽数字，避免跳动）

## 5. 交互与实时

| 场景 | 行为 |
|---|---|
| SSE 新预测 | 对应卡片数值 300ms 数字滚动；修订则红点脉冲 3 次 |
| SSE 行情异动 | 该品种卡片短暂描边高亮 |
| 断线 | Header 状态灯转灰，顶部细条提示「连接中断，正在重连」 |
| 重连成功 | 静默拉一次全量 dashboard，补齐错过的更新 |
| 页面隐藏 | 暂停 SSE、暂停轮询（省电省流量） |
| 下拉刷新 | PWA 生效，触发全量刷新 |
| 离线 | 展示缓存卡片 + 顶部「离线数据，更新于 xx:xx」 |
| 冷启动 | 先渲染本地缓存，再后台刷新（stale-while-revalidate） |

## 6. 详情抽屉规格

- 桌面：右侧 480px 抽屉；移动：底部全屏 sheet（可下拉关闭）
- 打开 ≤200ms：数据来自首页已加载对象，不二次请求（趋势图按需拉）
- 区块顺序固定：概览 → 趋势 → 贡献者 → 因子权重 → 资讯证据 → 置信度 → 修订历史
- 贡献者条形：正贡献红、负贡献绿，长度按绝对值归一
- 每个贡献者右侧显示 `权重 × q`，点击展开机理说明（来自知识库 YAML 的 `mechanism`）

---

## 7. 文案规范

| 场景 | ❌ 不要 | ✅ 要 |
|---|---|---|
| 弱信号 | 「上涨 82.9」 | 「震荡 8」或「偏多 12」 |
| 无资讯 | 「暂无资讯」 | 「今日无边际信息，依据季节性：11 月入库季」 |
| 数据缺失 | 「0」 | 「外盘缺失，已下调置信度」 |
| 免责 | 长段落 | 页脚一行：「个人研究用途，不构成投资建议」 |

## 8. 可用性验收

- [ ] iPhone SE (375×667) 首屏可见 ≥2 张卡片，无横向滚动
- [ ] 卡片信息在 3 秒内可读出「品种 + 方向 + 幅度 + 时间」
- [ ] 色盲模式下（去色）仍能区分方向（箭头 + 文字）
- [ ] 弱网（3G 模拟）首屏骨架 → 内容 ≤3s
- [ ] Lighthouse：Performance ≥ 85，PWA 可安装
- [ ] 所有可点区域 ≥44×44px
