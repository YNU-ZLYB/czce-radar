# 郑商所品种产业链与传导权重手册（v2 已按你的意见修订）

> 用途：这是「期货雷达」研判模型的**知识底座**。请你逐条核实，确认后我再把它写进系统的因子配置与权重表。
> 说明：所有数值是**先验经验权重**（0–1），后续会用真实数据校准，不是拍脑袋的最终值。

---

## 一、为什么要改：现在的问题

现在的研判是「关键词命中 → 判多空」。问题有三个：

1. **没消息就空白**：某品种当天没新闻，卡片只能跟着盘面走，没有前瞻预判。
2. **消息是点，产业链是面**：一条「某装置检修」只是产业链上的一个点，真正决定方向的是「供给收缩 vs 需求走弱 vs 库存高低」的合力。
3. **外盘只用了价格，没用逻辑**：同样是原油涨 1%，对 PX 和纯碱的意义完全不同。

所以改成**三层打分（不含盘面）**：

| 层 | 内容 | 数据频率 | 权重（可调） |
|---|---|---|---|
| L1 资讯层 | 新闻/公告 → 多空 + 强度 | 分钟级 | 45% |
| L2 产业链层 | 开工率、库存、利润、价差、产能变化 | 日/周/月 | 35% |
| L3 传导层 | 外盘与关联品种涨跌 × 传导权重 | 分钟级 | 20% |
| （参考）盘面 | 主力涨跌、持仓变化、基差 | 分钟级 | **不计入权重，只在卡片上单独展示** |

最终分 = L1×0.45 + L2×0.35 + L3×0.20。

**设计原则（已与用户确认）**：盘面只展示、不参与打分。因为把当日涨跌算进去，会变成「跟着行情复述」，看起来准，实际没有预测价值。预测必须来自资讯、产业链与外盘传导，盘面仅用于事后对照。

## 二、权重怎么定（你提到的神经网络/随机森林）

**结论：先用产业逻辑给先验权重，再用机器学习校准，不要一上来上神经网络。**

原因：

- 单品种的产业链指标大多是**周频/月频**，一年才 50 个点左右，神经网络参数几百上千，必然过拟合。
- 期货更看重**可解释**：你看到「甲醇看跌 83」，必须能说清是煤价、伊朗限气还是港口累库导致的。
- 正确做法（我会这么实现）：
  1. **先验**：本手册的权重，先跑起来；
  2. **特征**：库存分位数、开工率同比、加工费分位数、基差、外盘动量，每个品种 8–15 个；
  3. **校准**：用**逻辑回归 + 梯度提升树（GBDT）**，标签是「未来 1 日 / 5 日涨跌」，输出各特征重要性和方向；样本量够（≥300 条）再考虑浅层模型；
  4. **严格按时间切分**：不允许随机打乱。用「滚动前推」——用 2023 年训练、2024 年验证、2025 年测试，逐月向前滚动，绝不使用未来数据；
  5. **人工兜底**：模型权重和产业逻辑冲突时，以逻辑为准，并在卡片上标注「模型与经验背离」。

如果你就是想要神经网络，我可以上一个小型 MLP（2 层），但会同时保留 GBDT 作为对照，谁的回测胜率高用谁。

## 三、逐品种产业链与先验权重

> 权重含义：**上游成本项 / 外盘对标 / 关联品种**对国内该品种价格的传导强度（0–1）。
> 流动性标记：★★★ 好（可正常交易）、★★ 一般、★ 差（易被资金拉动，谨慎解读）。

### 1. 白糖 SR ★★★
- **产业链**：甘蔗/甜菜（广西、云南、内蒙、新疆）→ 糖厂压榨 → 白砂糖；进口原糖（巴西、泰国、印度）→ 加工糖；替代品：淀粉糖（玉米）
- **核心指标（免费可跟）**：广西/云南产销率（月）、巴西 UNICA 双周报、印度/泰国产量与出口政策、进口量与内外价差、淀粉糖-白糖价差、郑商所仓单
- **利多**：巴西/印度减产、国内霜冻或干旱、进口成本抬升、夏季饮料消费旺季、国家收储
- **利空**：进口放量、抛储、全球过剩、淀粉糖替代、走私糖冲击
- **传导权重**：ICE 原糖 0.60 / 布伦特（乙醇平价比）0.15 / 美元指数 0.05
- **季节性**：11–12 月开榨压力最大；5–8 月消费旺季；9–10 月青黄不接易涨

### 2. 棉花 CF ★★★
- **产业链**：籽棉 → 轧花厂 → 皮棉 → 纺企 → 纱/布 → 服装出口（新疆产量占全国 90%+）
- **核心指标**：新疆植棉面积与单产、籽棉收购价、USDA 供需报告（月度）、滑准税配额、纺企开机率与订单、仓单
- **利多**：新疆减产、抢收抬价、配额收紧、纺织旺季、轮入
- **利空**：丰产、进口放量、抛储、纺织淡季、涤纶短纤替代
- **传导权重**：ICE 美棉 0.65 / 涤纶短纤（替代）0.10 / 美元 0.05
- **季节性**：9–11 月新棉上市压力；3–5 月纺织旺季

### 3. 棉纱 CY ★★
- **产业链**：棉花 → 纺纱 → 棉纱 → 织布/服装
- **核心指标**：纺纱利润、开机率、纱厂库存、棉花价格
- **逻辑**：本质是「棉花 + 加工费」，方向跟随棉花，弹性更小
- **传导权重**：棉花 0.70 / ICE 美棉 0.35
- **利多/利空**：同棉花，另加「纺织订单外流东南亚」（利空）

### 4. 甲醇 MA ★★★
- **产业链**：煤/天然气 → 甲醇 → MTO（烯烃）、甲醛、醋酸、二甲醚、燃料；进口主要来自伊朗、阿曼、特立尼达
- **核心指标**：煤价、伊朗装置与冬季限气、港口库存（华东/华南）、MTO 开工与利润、烯烃价格
- **利多**：伊朗限气/装置故障、港口去库、MTO 利润修复、煤价上涨
- **利空**：进口集中到港、煤价下跌、烯烃亏损减产、新装置投产
- **传导权重**：布伦特 0.45（能化情绪+进口成本）/ NYMEX 天然气 0.30（伊朗成本）/ PP 0.20
- **季节性**：冬季伊朗限气（11–3 月）易涨；梅雨季累库偏弱
- **地缘敏感度**：★★★★★（中东、霍尔木兹、制裁）

### 5. 纯碱 SA ★★★
- **产业链**：原盐 + 石灰石 + 煤/天然气 → 纯碱（氨碱/联碱/天然碱）→ 浮法玻璃、光伏玻璃、碳酸锂、洗涤剂
- **核心指标**：开工率与检修计划、厂库库存、重碱需求（浮法+光伏日熔量）、天然碱新增产能
- **利多**：集中检修、光伏玻璃点火、厂库快速去化、环保限产
- **利空**：新增产能投放、玻璃冷修、进口碱、需求走弱
- **传导权重**：玻璃 0.35（需求端）/ 天然气+煤 0.30（成本）/ 光伏装机 0.15
- **季节性**：春节前后累库；夏季检修季偏强

### 6. 玻璃 FG ★★★
- **产业链**：纯碱 + 燃料（天然气/石油焦/煤）→ 浮法玻璃 → 地产竣工、汽车、光伏
- **核心指标**：地产竣工与新开工、浮法日熔量、厂库、现货产销率、保交楼政策
- **利多**：保交楼/竣工回升、冷修增加、政策刺激
- **利空**：地产下行、累库、复产点火、梅雨季需求停滞
- **传导权重**：纯碱 0.30（成本）/ 地产销售与竣工 0.35 / 天然气 0.15
- **季节性**：金九银十（9–10 月）偏强；梅雨季（6–7 月）偏弱

### 7. PX 对二甲苯 ★★
- **产业链**：石脑油 → PX → PTA → 聚酯 → 纺织；国内进口依赖度高（日韩）
- **核心指标**：原油与石脑油价差、PX-石脑油加工费、亚洲装置检修、PTA 开工率
- **利多**：亚洲装置检修、原油上涨、加工费低位
- **利空**：新装置投产、原油下跌、PTA 减产
- **传导权重**：布伦特 0.65 / 石脑油 0.20 / PTA 0.15
- **地缘敏感度**：★★★★★

### 8. PTA ★★★
- **产业链**：PX → PTA → 聚酯（长丝/短纤/瓶片）→ 纺织与包装
- **核心指标**：PX 成本、PTA 加工费、聚酯开工与库存、旺季订单
- **利多**：装置检修、聚酯高开工、原油上涨
- **利空**：新产能、聚酯减产、原油下跌、出口受阻
- **传导权重**：布伦特 0.55 / PX 0.30 / 聚酯开工 0.15
- **地缘敏感度**：★★★★☆

### 9. 瓶片 PR ★★
- **产业链**：PTA + 乙二醇 → 瓶级切片 → 饮料瓶、出口
- **核心指标**：PTA/EG 成本、饮料旺季（4–9 月）、出口订单、加工费
- **利多**：旺季、出口好转、装置减产
- **利空**：新产能、淡季、原料下跌
- **传导权重**：布伦特 0.50 / PTA 0.30 / 乙二醇 0.10

### 10. 短纤 PF ★★
- **产业链**：PTA + 乙二醇 → 涤纶短纤 → 纱线、无纺布
- **核心指标**：原料成本、纯涤纱开工、终端订单、与棉花价差
- **利多**：旺季、减产、原料上涨
- **利空**：累库、需求走弱、棉花下跌
- **传导权重**：布伦特 0.50 / PTA 0.25 / 棉花 0.10

### 11. 烧碱 SH ★★
- **产业链**：原盐 + 电 → 烧碱（离子膜）→ 氧化铝、造纸、化纤、水处理；副产液氯
- **核心指标**：氧化铝开工（最大下游）、氯碱平衡（液氯价格）、检修、出口
- **利多**：氧化铝高开工、集中检修、出口好转、液氯胀库倒逼降负
- **利空**：氯碱企业增产、氧化铝减产、需求淡季
- **传导权重**：布伦特 0.25（能化情绪）/ 天然气 0.25 / 氧化铝 0.25
- **注意**：烧碱与液氯是「联产品」，只烧碱涨、液氯跌时利润不一定好

### 12. 尿素 UR ★★★
- **产业链**：煤/天然气 → 合成氨 → 尿素 → 农业（玉米/水稻追肥）、工业（三聚氰胺、脲醛、车用尿素）
- **核心指标**：煤价与气头成本、日产与开工率、农需季节、出口政策（法检/配额）、印度招标
- **利多**：气头限气、印度招标放量、出口政策放松、农需旺季
- **利空**：日产高位、出口收紧、淡季累库、储备投放
- **传导权重**：天然气 0.30 / 动力煤 0.30 / CBOT 玉米 0.15
- **季节性**：3–7 月用肥旺季；9 月后转淡

### 13. 菜籽油 OI ★★
- **产业链**：油菜籽（加拿大进口 + 国内长江流域）→ 压榨 → 菜油；替代：豆油、棕榈油
- **核心指标**：加拿大菜籽产量与对华出口政策、豆油/棕油价差、国内库存、抛储
- **利多**：加拿大减产、中加关系紧张、油脂整体上涨
- **利空**：进口放量、抛储、豆棕油下跌
- **传导权重**：CBOT 豆油 0.50 / 加拿大菜籽 0.25 / 棕榈油 0.15 / 布伦特（生柴）0.10

### 14. 菜籽粕 RM ★★
- **产业链**：菜籽压榨副产物 → 水产饲料、禽料；主要替代品：豆粕
- **核心指标**：加拿大菜籽、豆菜粕价差、水产旺季（4–9 月）、进口量
- **利多**：水产旺季、豆粕上涨、加籽减产
- **利空**：豆粕下跌、进口放量、水产淡季
- **传导权重**：CBOT 豆粕 0.50 / CBOT 大豆 0.20 / 加拿大菜籽 0.20
- **这正是你说的「豆粕跟美豆有关」的落点**

### 15. 油菜籽 RS ★
- **产业链**：加拿大/欧洲/国内菜籽 → 压榨（油+粕）
- **核心指标**：加拿大产量与出口、进口利润、国产菜籽收购价
- **注意**：流动性极差，**不建议单独作为交易依据**，只作为菜油/菜粕的原料端参考
- **传导权重**：加拿大菜籽 0.60 / CBOT 大豆 0.20

### 16. 苹果 AP ★★
- **产业链**：种植（陕西、山东）→ 冷库 → 批发 → 零售；替代：梨、柑橘等时令水果
- **核心指标**：4–5 月花期霜冻与冰雹、优果率、入库量、冷库去库速度、替代水果价格
- **利多**：霜冻/冰雹减产、好果率低、去库快、替代品贵
- **利空**：丰产、入库量大、消费疲弱
- **传导权重**：无外盘对标；主要看天气与替代品（属「气候驱动型」品种）
- **季节性**：10–11 月入库定产；5 月后看天气与库存

### 17. 红枣 CJ ★
- **产业链**：新疆灰枣（产量高度集中）→ 加工 → 商超/电商
- **核心指标**：新疆产量与品质、开秤价、库存、消费
- **利多**：减产、开秤价高、节日消费
- **利空**：丰产、库存高、消费疲软
- **说明**：方向研判**不打折**（与棉花、甲醇同等对待），但卡片上加一个「流动性偏低」标签，提示执行滑点和跳空风险——打折会污染预测，标签只提示交易风险，二者分开。

### 18. 花生 PK ★★
- **产业链**：花生仁 → 压榨（花生油+花生粕）/ 食品；进口来自苏丹、塞内加尔
- **核心指标**：河南山东产量与天气、进口量、油厂收购价、豆油/棕油替代
- **利多**：减产、进口减少、油厂抢收
- **利空**：丰产、进口放量、油脂下跌
- **传导权重**：CBOT 豆油 0.20 / 棕榈油 0.15

### 19. 硅铁 SF ★★
- **产业链**：硅石 + 兰炭 + 电 → 硅铁 → 钢厂（脱氧剂）、镁厂
- **核心指标**：电价与能耗双控政策、钢厂利润与粗钢产量、兰炭价格、宁夏/内蒙/青海限电
- **利多**：限电/能耗政策、钢厂复产、兰炭上涨
- **利空**：钢厂减产、电价下调、复产增产
- **传导权重**：螺纹钢 0.35 / 动力煤（电价）0.25 / 锰硅联动 0.10
- **特点**：政策驱动极强，一条限电通知能涨停

### 20. 锰硅 SM ★★
- **产业链**：锰矿（南非/澳洲/加蓬）+ 焦炭 + 电 → 锰硅 → 钢厂
- **核心指标**：锰矿价格与港口库存、South32 等矿山供应事件、钢厂需求、产区电价
- **利多**：锰矿上涨/断供、限电、钢厂复产
- **利空**：锰矿下跌、钢厂减产、电价下调
- **传导权重**：锰矿 0.40 / 螺纹钢 0.30 / 电价 0.20
- **特点**：2024 年 South32 事件证明「单一矿端事件」可以主导行情

### 21. 丙烯 PL ★★
- **产业链**：石脑油裂解 / 丙烷脱氢（PDH）/ 煤制烯烃 → 丙烯 → 聚丙烯 PP、环氧丙烷、丙烯腈、丁辛醇
- **核心指标**：原油与石脑油、丙烷 CP/FEI 价格与 PDH 利润、PP 开工、新增产能
- **利多**：原油/丙烷上涨、PDH 亏损减产、PP 旺季
- **利空**：新产能集中投产、原油下跌、PP 需求弱
- **传导权重**：布伦特 0.50 / 丙烷（FEI）0.25 / PP 0.20
- **地缘敏感度**：★★★★☆（丙烷进口依赖中东/美国）

3. **低流动性品种不打折**：方向研判一视同仁，只加「流动性偏低」标签。理由：打折会把预测和交易风险混为一谈；预测该多准就多准，风险单独提示。

## 八、历史回测方案（替代「先跑三个月」）

**可以，而且比等三个月靠谱。** 设计如下：

### 1. 数据
- **价格**：各品种主力连续日线（新浪/交易所历史），至少回补 3 年
- **资讯**：按发布时间回补（金十/东财历史快讯、USDA/MPOB/UNICA 历史报告摘要）
- **外盘**：布伦特、WTI、美豆、美豆粕、美豆油、美棉、原糖、天然气、铜的日线
- **产业链**：仓单日报（交易所历史可下载）、检修公告（按日期归档）

### 2. 切分方式（严格按时间，绝不随机打乱）
- 训练：2023-01 ~ 2024-06
- 验证：2024-07 ~ 2025-06
- 测试：2025-07 ~ 至今
- 然后**逐月向前滚动**（walk-forward），每次只用该时点之前的数据训练

### 3. 标签
- 次日方向：涨 = 1，跌 = 0（剔除 |涨跌|<0.3% 的无效样本）
- 辅助标签：未来 5 日累计收益

### 4. 评价指标（比"准确率"更关键）
| 指标 | 含义 | 及格线 |
|---|---|---|
| 方向准确率 | 猜对多空的比例 | > 53% |
| IC / RankIC | 情绪分与次日收益的相关性 | > 0.05 |
| 多空分层收益 | 按情绪分 5 档，最高档减最低档的收益差 | > 0 且单调 |
| 最大回撤 | 按信号交易的净值回撤 | 可控 |

### 5. 防坑
- **未来函数**：所有特征只用「发布时点之前」的数据；日报类指标按**发布日**而非统计期对齐
- **幸存者偏差**：停用品种（ZC/WH）不纳入训练
- **过拟合**：参数越少越好，GBDT 限制树深 ≤4、学习率 0.05、强正则
- **样本外**：测试集只用一次，不给调参机会

### 6. 产出
- 一份《回测报告》：每个品种的准确率、IC、分层收益，以及最终采用的权重
- 回测通过的权重才写入线上系统；不通过就保留先验权重并标注「未校准」
