# 00 · 需求与定位

> 项目代号：**CZCE Radar v2**（郑商所品种预测与研判系统）
> 文档状态：待评审
> 关系：完全新建代码库，v1（`futures-radar`）只作参考与数据资产来源，不继承其代码结构。

---

## 1. 起点：v1 到底错在哪

复盘 v1 的五类错误。新系统在设计上逐条对冲，这是本项目的"宪法"。

| # | v1 的错误 | 后果 | v2 的对策 |
|---|---|---|---|
| E1 | **把"资讯打分"当成"预测"** | 消息出来才评论，用户看到的是"事后诸葛亮" | 预测与研判物理分表；卡片只渲染 Prediction |
| E2 | **预测时点不严格，存在未来函数风险** | 结果虚高、无法回测、越用越不信 | 强制 asof 时间戳，训练/推理走同一份 Feature Snapshot |
| E3 | **权重靠拍脑袋，没有统计校准** | 无效传导（纯碱←天然气）也在展示 | 机理权重 × 回测校准系数 q；q 不显著直接置 0 并隐藏 |
| E4 | **单进程 + SQLite 混跑采集/计算/接口** | 沙箱重启即丢、并发锁、一个超时全卡 | 三层分离：采集进程 / Worker 进程 / API 进程，PostgreSQL 单一可信源 |
| E5 | **"强度"是情绪分，不是可验证的量化目标** | 用户不知道 22.0 和 82.9 差在哪、准不准 | 预测目标严格定义为「下一交易日涨跌三分类 + 幅度分档」，强度=概率×幅度 |

v1 唯一值得继承的是**数据资产与实证结论**（见 `docs/refs/`）：

- 隔夜外盘传导方向命中率 **57.0%（全样本）/ 62.1%（|外盘合计|≥0.8%）**，样本外 4344 条；
- 短周期盘面动量 IC ≈ −0.06~+0.01，**无预测力** → 盘面只展示、不进权重（与用户判断一致）；
- 多因子线性模型 IC 0.29 但方向命中 49.4% → **只能排序，不能报方向**；
- 纯碱/玻璃/尿素/烧碱的"天然气成本传导"日频被证伪 → 置 q=0。

## 2. 用户与场景

**唯一用户**：本人（个人决策辅助，非商业产品）。
**设备**：手机为主（PWA 添加到主屏幕），电脑为辅。
**使用节奏**：

```
08:25  打开首页 → 21 张卡片，看今天哪些品种有"有把握的方向"
       点开异常卡片 → 看贡献者拆解（外盘/产业链/季节性/资讯）与置信度
盘中   有异动推送 → 卡片变红点，判断是否需要修订
15:10  收盘后自动生成 Scorecard：今天预测对了吗？错在哪一环？
周末   看本周命中率曲线，决定要不要调模型版本
```

**核心诉求（用户原话提炼）**：
1. "要提前于现有消息的预测，不是等消息出来再搬过来。"
2. "不要光收集资讯，要收集国内外不同期货的价格波动，它会带动国内同向变动。"
3. "先整理每个品种的产业链、产业链变动带来的利空利好，生成文档我核实。"
4. "让模型根据产业链消息自己定权重，加到利空利好评判里。"
5. "用历史消息训练，严格按时间划分训练/测试集，用历史盘面评判效果。"
6. "卡片只要方向和大小、传导链；其他点开再看。"
7. "每个品种单独显示更新时间。"
8. "动力煤、小麦删掉；菜籽、菜油、菜粕都要研判。"
9. "盘面不要进权重，会导致看着准、实际不真。"

## 3. 需求基线

优先级：P0 = 不做就没有存在意义；P1 = 核心体验；P2 = 增强；P3 = 可选。

### P0 · 预测内核

| ID | 需求 | 验收标准 |
|---|---|---|
| R-01 | **T 日开盘前预测 T 日方向** | 每日 08:30 前，21 品种全部产出 Prediction，无一为空 |
| R-02 | 输出三分类概率 + 幅度分档 | P(涨)/P(跌)/P(震荡) 之和=1；幅度档位 ∈ {强多, 偏多, 震荡, 偏空, 强空} |
| R-03 | **置信度经过校准** | 置信度 70% 的预测，实际命中率落在 65%~75%（可靠性曲线） |
| R-04 | 严格无未来函数 | 回测与线上走同一 `FeatureSnapshot(asof)`；CI 有泄漏检测 |
| R-05 | 权重由回测校准 | 每个贡献者带 `manual_weight` 与 `calibrated_q`，前端可查来源 |
| R-06 | 预测可解释 | 每张卡片可展开贡献者明细（名称/数值/权重/贡献） |

### P1 · 产业链与外盘

| ID | 需求 | 验收标准 |
|---|---|---|
| R-07 | 产业链知识库覆盖 21 品种 | 每品种：上游/中游/下游、成本项、库存指标、季节性、典型事件，人工核实通过 |
| R-08 | 外盘行情 60s 级 | 原油(WTI/Brent/SC)、美棉、美豆/粕/油、玉米、小麦、天然气、铜、美元指数 |
| R-09 | 国内 21 品种主力行情 60s 级 | 价格/涨跌/成交/持仓/仓单 |
| R-10 | 外盘传导信号 | 传导命中率显著（≥55%）才展示；否则隐藏 |
| R-11 | 产业链指标（免费可得） | 仓单、库存、现货价/基差（AKShare 等），每日更新 |
| R-12 | 季节性因子 | 月度/阶段偏移进入特征，非硬编码结论 |

### P1 · 资讯与修订

| ID | 需求 | 验收标准 |

## 4. 明确的非目标

写在方案里，避免范围蔓延：

- ❌ 不做自动交易、不做下单、不接券商
- ❌ 不做多用户、不做登录体系、不做付费订阅
- ❌ 不做全市场全品种（只郑商所活跃品种 + 必要外盘）
- ❌ 不做秒级/高频（目标：分钟级行情 + 日频预测）
- ❌ 不做"AI 自动选股式黑箱"——所有结论必须可拆解到贡献者
- ❌ 不追求"每天都有强观点"——**没有信号就老实说震荡**，这是本产品的诚实性卖点

## 5. 成功标准（可量化，季度复核）

| 指标 | 目标 | 说明 |
|---|---|---|
| 方向命中率（样本外，滚动 60 日） | ≥ 55% | 基线：全涨基线≈52%（需按实际分布重算） |
| Balanced Accuracy | ≥ 0.55 | 防类别不平衡虚高 |
| Brier Score | ≤ 0.23 | 三分类校准质量 |
| 置信度可靠性误差 | ≤ 0.05 | 可靠性曲线与对角线平均偏差 |
| 每日 08:30 出预测成功率 | ≥ 99% | 21 品种全出 |
| 采集任务成功率 | ≥ 95% | 单源失败不影响整体 |
| 手机首屏可用时间 | ≤ 3s | 4G 网络 |
| 月度 LLM 成本 | ≤ ¥50 | 缓存命中率 ≥ 60% |

> 注：55% 看似不高，但期货日频方向预测的公开研究中，稳定超过 55% 已具备经济价值。我们不承诺神准，承诺**可验证、可解释、持续改进**。
